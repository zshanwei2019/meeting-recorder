# 🎙️ 会议录音转写助手

自动检测腾讯会议启动，自动录音并语音转写为文字。

## ✨ 功能特点

- **自动检测** — 监控腾讯会议进程，开会自动录音，结束自动停止
- **系统音频捕获** — 直接录制电脑播放的声音，无需麦克风
- **本地语音转写** — 使用OpenAI Whisper模型，无需联网，隐私安全
- **带时间戳** — 转写结果包含时间标记，方便回溯
- **系统托盘** — 最小化到托盘，后台静默运行
- **深色主题** — 护眼UI

## 🚀 快速开始

### 1. 安装依赖
双击 `install.bat`，自动安装所有依赖包

### 2. 启动程序
双击 `run.bat`，或在命令行运行：
```
python meeting_recorder.py
```

### 3. 使用方式
- **自动模式**：点击"🔍 自动监控"，程序自动检测腾讯会议启停
- **手动模式**：点击"⏺ 手动录音"，随时开始/停止
- **转写**：点击"📝 转写录音"，选择音频文件进行转写

## 🔊 系统音频设置

如果无法录制系统声音（会议声音），需要启用"立体声混音"：

1. 右键点击右下角音量图标
2. 选择"声音设置"
3. 点击"更多声音设置"（或"声音控制面板"）
4. 切换到"录制"标签
5. 右键空白处，勾选"显示已禁用的设备"
6. 找到"立体声混音"，右键启用并设为默认

**替代方案**：安装 [VB-Audio Virtual Cable](https://vb-audio.com/Cable/)（免费虚拟音频线）
